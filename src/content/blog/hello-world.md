这个网站已经准备好承载新的内容。

以后写文章，只需在 `src/content/blog` 中新建一个 Markdown 文件，填写标题、摘要、日期和标签，然后开始写正文。推送到 GitHub 后，网站会自动完成构建与发布。

## 图片与动态图片

可以把图片或 GIF 和文章放在同一个文件夹中，再用普通的 Markdown 语法引用：

```md
![图片说明](./image.png)
![动态演示](./demo.gif)
```

这样文章与它使用的素材会始终待在一起，移动和备份都很方便。

## 草稿

暂时不想公开的内容，将文章开头的 `draft` 设置为 `true` 即可。它不会出现在正式构建的网站中。
